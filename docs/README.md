# 即时通讯 MeChat

## 项目文件结构

```txt
mechat/
│── build/                  # 编译输出目录
│── config/
│   │── config.json         # 配置文件
│── docs/
│   │── API.md
│   │── DATABASE.md 
│   │── README.md
│── include/                # 头文件目录
│   │── common.hpp
│   │── database_pool.hpp
│   │── logger.hpp
│   │── message.hpp 
│   │── server.hpp        
│   │── session_manager.hpp 
│   │── session.hpp
│── logs/                   # 服务器日志文件存放目录   
│── src/
│   │── database_pool.cpp   # 数据库连接池
│   │── logger.cpp          # 网络日志记录
│   │── main.cpp            # 入口文件，启动 WebSocket 服务器
│   │── message.cpp         # 消息结构体 实现
│   │── server.cpp          # 服务器核心逻辑
│   │── session_manager.cpp # 管理 session 会话
│   │── session.cpp         # WebSocket 会话管理
│── tests/
│   │── test_server.cpp     # 测试 WebSocket 服务器
│   │── test_session.cpp    # 测试 WebSocket 会话
│── third_party/            # 第三方库（如 Boost）
│── CMakeLists.txt          # CMake 构建配置
```

## 项目开发规划

🟢已实现 🔴待实现 🔵暂不开发

### **一、核心基础功能**

1. **通信框架**
   - 🟢异步网络层
   - 🟢通信协议解析基础模块
   - 🟢基础Session管理容器

2. **开发调试工具**
   - 🟢日志系统
   - 🟢自动化测试框架
   - 🟢内存泄漏检测

3. **基本安全设计**
   - 🟢WSS加密通信
   - 🔵连接频率限制
   - 🔵基础DDOS防护（IP黑名单）

---

### **二、用户系统**

1. **数据存储**
   - 🟢数据库选择（MySQL/MongoDB/Redis组合）
   - 🟢用户表（含索引优化）
   - 🟢数据库连接池

2. **用户管理**
   - 🟢注册/登录/注销
   - 🟢密码安全存储
   - 🟢会话管理（JWT令牌机制）

3. **基础关系网络**
   - 🔴好友添加/删除/黑名单功能
   - 🔵用户状态同步（在线/离线/忙碌）
   - 🔵基础用户资料存储（昵称/头像URL）

---

### **三、单聊功能**

1. **核心消息传输**
   - 🔴消息存储转发（离线消息支持）
   - 🔵消息状态跟踪（已发送/已送达/已读）

2. **消息可靠性**
   - 🔴消息ACK确认机制
   - 🔴消息重传策略（超时重发）
   - 🔴消息去重设计（msg_id判重）

3. **历史消息管理**
   - 🔴消息本地缓存策略
   - 🔴分页拉取历史消息
   - 🔴消息云端漫游

---

### **四、群组功能**

1. **建立群组**
   - 🔴群创建/解散/加入/退出
   - 🔵群权限管理（管理员/禁言设置）
   - 🔴群资料修改（公告/群名）

2. **群消息**
   - 🔴高效群消息广播
   - 🔴@提及功能
   - 🔴群消息免打扰模式

3. **大群支持**
   - 🔵分片存储群成员列表
   - 🔵消息扩散优化（读扩散 vs 写扩散）
   - 🔴群活跃度监控系统

---

### **🔵五、体验优化**

1. **多端同步**
   - 实现Web/PC/Mobile三端消息同步
   - 处理设备登录冲突
   - 开发消息推送服务（APNs/FCM）

2. **富媒体支持**
   - 文件传输（断点续传/秒传）
   - 图片/视频缩略图生成
   - 语音消息录制播放

3. **UI/UX优化**
   - 消息气泡样式引擎
   - 输入状态提示（正在输入...）
   - 消息撤回/编辑功能

---

### **🔵六、性能优化与安全加固**

1. **架构优化**
   - 引入消息队列（Kafka/RabbitMQ）
   - 实现分布式Session管理
   - 开发连接预热机制

2. **安全体系**
   - 全链路HTTPS
   - 敏感操作二次验证
   - 消息端到端加密

3. **监控体系**
   - 搭建Prometheus+Grafana监控
   - 实现异常行为检测
   - 开发自动化压测工具

---

### **🔵七、部署与运维**

1. **生产环境部署**
   - Nginx反向代理配置
   - 实现灰度发布方案
   - 搭建CI/CD流水线

2. **运维工具开发**
   - 用户行为分析看板
   - 消息追踪调试工具
   - 自动化扩缩容策略

---

### **开发策略**

1. **开发策略**

   - 模块化开发特定功能
   - 清晰定义模块接口
   - 优先实现核心功能
   - 定时 Code Review

2. **文档策略**

   - 为每个接口编写详细的API文档
   - 定时进行技术总结

3. **测试策略**

   - 为每个功能模块编写单元测试
   - 集成测试各个模块间的协作表现
